## 💪 Rules that actually work

1. **Miss a day? Don't double up.** Just continue — consistency beats intensity.
2. **Type, don't read.** Muscle memory is real for syntax.
3. **Dry run on paper** before running loop/recursion code.
4. **Explain out loud** (rubber duck 🦆) — if you can't explain it, you don't know it yet.
5. Tick the ☐ boxes — the dopamine is free.
